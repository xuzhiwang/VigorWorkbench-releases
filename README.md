# VigorWorkbench-releases

This public repository hosts **release artifacts only** for VigorWorkbench Windows auto-updates.

GitHub Releases here are the electron-updater feed. Typical assets:

- `latest.yml`
- `VigorWorkbench-Setup-*-x64.exe`
- `.blockmap` files

## Source

Application source is private: [xuzhiwang/VigorWorkbench](https://github.com/xuzhiwang/VigorWorkbench).

This repo does **not** contain app source, secrets, tokens, or signing keys.

## Clients

Installed clients read public GitHub Releases from this repository. No authentication is required to fetch update metadata or installer assets.
